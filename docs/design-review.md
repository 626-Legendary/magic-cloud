# Design.md 对照检查

检查日期：2026-11-17。基线：根目录 Design.md，结合用户后续明确要求。检查对象为当前 Vue 实现及本机部署的页面。

以下问题为修复前检查快照；本轮处理结果见文末“修复落地状态”及 [前端设计实现](ui-design.md)。

本次仅检查，未修改产品代码、配置、数据或部署。浏览器在独立上下文中拦截全部 `/api/**` 请求并返回虚拟数据，检查文件页、设置页、弹窗与移动抽屉；未使用真实账户密码，也未发送真实写操作。结论不代表完整 WCAG 合规认证。

## 优先修复

### 1. 搜索框缺少可见键盘焦点（高优先级）

- 规范：4.5、10、11，所有交互元素保留可见焦点。
- 位置：`frontend/src/style.css:559`。
- 实现：`.search input` 使用 `outline: none !important`，同时无边框、无替代焦点样式。
- 浏览器复现：聚焦后计算样式为 outline-style `none`、box-shadow `none`、border-width `0px`。
- 建议：删除强制移除焦点的规则，并为输入框或搜索容器增加符合规范的焦点环。

### 2. 移动端抽屉的隐藏和键盘行为不完整（高优先级）

- 规范：4.7、7.11、11，抽屉和完整键盘操作。
- 位置：`frontend/src/style.css:1436`、`frontend/src/App.vue:881`、`frontend/src/App.vue:945`。
- 实现：侧栏关闭时仅用 transform 移出屏幕，内部链接仍可聚焦；打开按钮也未关联展开状态。
- 浏览器复现：320px 视口中，Tab 可落在侧栏“最近文件”链接，其矩形 x=-226、right=-19，完全位于屏幕外；打开抽屉后按 Esc，抽屉仍打开。
- 建议：关闭时将侧栏设为 inert；打开时管理初始焦点和焦点范围，Esc 关闭并归还焦点，补齐 aria-expanded 与 aria-controls。

### 3. 深色导航对比度不足，主按钮未使用主题主色（高优先级）

- 规范：2.4、7.1、8、11。
- 位置：`frontend/src/style.css:28`、`frontend/src/style.css:93`、`frontend/src/style.css:478`。
- 浏览器复现：深色选中导航前景 `#267FFF`、背景 `#234F86`，按相对亮度计算对比度约 **2.19:1**，低于普通文字要求的 4.5:1。深色主按钮仍使用硬编码的 `#0D6EFD`。
- 另见：主色文字 `#267FFF` 在深色 surface `#162238` 上约 **4.21:1**；不能假设设计文档提供的所有颜色组合天然满足 AA。
- 建议：分离按钮背景、导航文字与链接文字 Token，为实际使用的前景/背景组合校验对比度。不要直接将所有蓝色替换成同一主题变量。

## 已符合或基本符合

- Vue 3 与 Lucide 图标体系统一；主要纯图标按钮已有 aria-label。
- 字体栈与规范一致；浅色及深色的主要背景、surface、sidebar、border、hover、selected 色值基本一致。
- 支持 Light、Dark、System，系统主题变化有监听；index.html 在应用前加载 theme.js 读取偏好。虽然使用同步外部脚本而非文档要求的内联脚本，已具备首屏前设置主题的机制。
- 主按钮为纯色，普通文件卡片和导航未滥用渐变；主要卡片 12px、弹窗 16px 圆角符合档位。
- 删除、永久删除、清空回收站与覆盖有二次确认，危险按钮使用 danger 样式。
- 使用原生 dialog；新建文件夹弹窗实测焦点进入输入框、Esc 可关闭。缺少可访问名称不等于完全没有焦点管理。
- 具备错误 alert、成功 status、加载、空状态和上传百分比；上传状态同时有文字说明。
- CSS 有 prefers-reduced-motion 规则；主要交互动效在 150–250ms 范围内。
- 320px 文件页抽查无横向溢出；桌面/移动端支持 Grid 与 List，预览槽保持正方形。
- Logo 通过图片复用，未发现修改源图颜色或造型的代码。

## 用户要求优先的差异

以下不应直接按旧文档改回，应先同步规范：

1. **默认 Grid**：用户明确要求“视图默认为非列表视图”。App.vue:90 保留此行为及用户保存的选择；Design.md 1.2、4.7 的移动默认 List 需更新。
2. **Hero.png**：用户明确要求首页左侧使用该插画。保留当前插画和响应式设计，将其记录为品牌区域的允许用法。
3. **Footer**：用户要求版权声明、自动年份及 `.env` 版本号。保留当前实现，无需恢复早前品牌句。
4. **Logo 尺寸**：用户要求在各品牌入口使用更新 Logo。当前登录标识 42px/移动 32px、公开页等小尺寸与第 9 节统一最小 48px 不一致；建议区分“品牌标识”与“吉祥物插画”，避免为了字面达标挤占移动端。

## 建议处理顺序与验证范围

先修复焦点、移动抽屉、对比度与表单/弹窗名称，再统一 Token、字号与主题，最后补齐文件卡片、搜索、Toast 和类型图标。不要为满足原始 Token 数值而降低实际对比度。

本次实际验证：源码对照、浏览器计算样式、无障碍树、模拟数据下的键盘操作、320px 布局与深色主题截图；对比度使用实际色值计算。没有执行完整屏幕阅读器、多设备触屏或所有交互流程审计，也没有重新运行与本次只读检查无关的后端测试。
