# 设计检查清单

本清单用于评审当前产品和后续改动，具体交互以 [界面规范](ui-design.md) 为准，验证方法见 [验证指南](validation.md)。

## 品牌与内容

- 产品名、小企鹅名称与 Logo 一致，中英文自然、简洁。
- 页面标题、说明和主操作层级明确，不重复显示无助于决策的信息。
- 登录页五项卖点对齐，英文标签不随意拆行。
- Footer 使用当前年份和构建版本。

## 文件管理

- 网格默认值与保存的视图选择一致，列表仍保持紧凑布局。
- 类型图标、颜色和后缀识别使用同一套规则。
- 文件名可辨认，后缀弱化但不丢失，完整名称仍可读取。
- 缩略图具有留白、圆角和稳定比例；复选框不遮挡内容。
- 卡片文字和日期边距充足；多选、批量移动和删除都有明确反馈。
- 新建与上传按钮的主次层级清晰，上传选择使用居中模态框。

## 详情与分享

- 文件详情的信息区包含名称、类型、大小和上传时间，无法确认的历史信息不伪造。
- 不支持在线预览时使用统一文案，并提供下载入口。
- 访客分享页不请求文件内容或缩略图，下载按钮清晰突出。
- 访客文件名最多出现两次；长名称和手机布局无溢出。
- 失效分享与网络问题使用准确且不同的提示。

## 视觉与可访问性

- 文字、链接、按钮与选中状态对比度按实际组合验证。
- 空状态插画大小、留白和操作与所在场景匹配。
- 模态框有名称，键盘焦点进入、循环、退出和返回行为正确。
- 菜单、复选框、表单与进度条具备可访问名称和状态。
- 320px、中英文、浅/深主题及减少动效均可正常使用。
- 成功、错误、加载、空状态和危险操作的反馈清晰一致。
