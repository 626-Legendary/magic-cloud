# v1.0 验收

仅使用专门的测试 USB、测试账号/域名和可丢弃文件，不拔除系统盘，不用真实唯一副本测试断电。

## 自动化

`deploy/scripts/check.sh` 用容器执行 Rust 格式/测试/Clippy、前端类型与生产构建/Vitest/依赖审计、脚本测试、Compose 解析和本机架构生产镜像构建。需要 Docker 权限、网络和足够构建空间。实际结果见 validation.md，不能把本清单当作已执行证明。

- 认证：错误密码、来源限流、CSRF/Origin、安全 Cookie、退出撤销、到期、配置更换和日志裁剪。
- 存储：非法名称、路径穿越、符号链接、文件替换、storage-id 改变、空库保护、在线备份完整性。
- 生命周期：重命名、移动、覆盖旧文件回收、恢复冲突、单独回收子项、同名目录重建隔离和 30 天清理。
- 一致性：覆盖物理重命名的每个阶段中断后前滚，重复恢复保持幂等。
- 上传：服务端任务和分片协议、重复完成/重复分片、最大尺寸、空间不足；前端 2×2 调度、暂停和重选文件摘要不匹配。
- 分享：稳定 ID、当前子树归属、新增子项、移出拒绝、过期/撤销及删除后恢复不重新开放。

## 服务器与数据盘手工流程

1. **纯 Docker 部署**：没有宿主机 Rust/Node 时构建并启动。检查非 root 身份、仅两个主要容器和不公开宿主机端口。
2. **未挂载/错盘**：停止 timer 和应用，卸载测试 USB，仅保留空挂载点。检查脚本及启动均失败，系统盘上不产生 files/数据库。接入另一 UUID 的 ext4 盘，同样失败。
3. **运行中拔盘**：建立测试文件与备份，启动分片上传，拔除测试 USB。确认新操作失败，后端退出或被监控停止，旧分享无法读取；记录内核、systemd 和应用日志，不应输出秘密。
4. **重插恢复**：重新连接同一测试 USB。确认重新按 UUID 挂载，storage-id 相同，容器 ID 发生变化。登录、读文件、下载、恢复上传并核验 SHA-256。错误磁盘不得触发恢复。
5. **服务器 重启**：上传及目录操作前后分别重启；验证 fstab/监控恢复、持久文件和稳定分享。
6. **受控断电**：在测试盘上重复覆盖/移动/恢复并断电；重启后数据库完整、原文件仍在原位或回收站、未完成操作可恢复或明确停止，不能静默丢失数据。
7. **异常库**：停服务后保留数据库副本，再模拟缺失/损坏。启动拒绝并锁止重试；只读诊断及人工恢复步骤可用。

## 浏览器与大文件

- 上传零字节、16 MiB 边界、多个文件、嵌套目录和 10,000,000,000 字节测试文件；多余一个字节应拒绝。下载后对比摘要。
- 上传时切到设置、其他文件夹和其他桌面标签，观察实际网络请求继续；同时活跃文件≤2、每文件分片≤2。
- 暂停/继续、断网/重连、刷新、关闭并重开、重启容器。24 小时内重选正确内容继续；同名同大小不同内容必须拒绝；过期临时文件清理。
- 触发 ENOSPC/EIO（仅测试盘），确认安全失败，不自动清空回收站；发布前看不到半成品。
- 登录后预览图片/音频/PDF/UTF-8 文本/代码；代码 HTML 不执行。视频仅封面/详情/下载，无 `<video>`。
- 分享文件、目录，创建新子目录，重命名/移动分享根、移出子项、撤销、过期、删除及恢复；无登录浏览器仅可逐文件下载，不能访问私人 API、系统目录或写操作。
- 桌面/平板/手机宽度检查中英文、浅/深/系统主题、键盘焦点、Esc 关闭弹窗、回收站、分享复制和浮动传输面板。
- 缩略图损坏输入、超大尺寸和连续图片/视频任务下观察内存/CPU；失败应降级图标，不能拖垮文件列表。
- 单独通过实际 Cloudflare 账户测试 10 GB 下载及 Range，检查当时条款与账户限制；在验收记录中写明网络、账户计划和测试结果。

浏览器自动化脚本为 `tests/browser.mjs`。它要求隔离 Chromium 的 CDP 端点、Playwright、`MC_TEST_ORIGIN` 和 `MC_TEST_PASSWORD`；只对可丢弃的测试部署运行，会真实创建目录、上传文件并生成分享。截图写入 `/tmp`，不包含真实用户数据。该流程单独执行，不由默认 check.sh 自动连接生产服务。

局域网入口追加验收：显式配置 LAN_BIND_ADDRESS/LAN_ORIGIN 后，通过非回环 IP 的普通 HTTP 页面测试登录、刷新、上传、下载、分享复制与退出；确认浏览器 isSecureContext=false 时上传校验仍正常。公网继续使用 Secure Cookie，LAN 与公网会话不得跨入口复用，未配置的 Origin/Host 和缺少 CSRF 的写操作必须拒绝。测试脚本为 tests/lan-browser.mjs。
