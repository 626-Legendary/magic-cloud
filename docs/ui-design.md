# 界面与交互规范

## 品牌与布局

产品名为 Magic Cloud（麦吉云），小企鹅英文名为 Magi。各页面复用 `/Logo.png`，登录页使用 Hero 插画。Footer 显示当前年份和构建时的 `APP_VERSION`。

界面提供中文、英文及浅色、深色、跟随系统三种外观。登录页五项卖点使用居中的 3+2 布局，图标与文字按列排列，避免标签被随意拆行。桌面使用固定侧栏，手机使用带焦点管理的导航抽屉。未知路径显示统一风格的 404 页面。

## 设计变量

颜色、间距、字体、圆角、层级和阴影集中维护在 `frontend/src/tokens.css`。界面文字使用语义变量，文件类型色与正文文字色分开。正文、标签、按钮与选中状态应按实际前景/背景组合检查对比度；类型图标作为装饰，不承担唯一的信息表达。

常规操作图标使用 16/20/24px；文件图标与插画可以使用更大尺寸。触控控件至少保留可见文字或可访问名称。动效尊重 `prefers-reduced-motion`。

## 文件管理

- 默认使用网格视图，保留用户保存的网格/列表选择。列表行高 48px，表头 40px。
- 文件网格采用方形浅色预览区。文件夹为品牌蓝渐变实体造型，文档为纸张与类型标签，音频为深蓝波形封面；其余类型使用对应 Lucide 图标。
- 缩略图统一使用保留 Alpha 通道的 PNG，透明区域显示预览底色。图片与视频缩略图保留 12px 内缩、8px 圆角及轻阴影。未就绪或失败时保留相应类型图标。
- 类型、后缀和图标映射分别集中在 `file-kind.ts` 与 `file-icons.ts`；不区分后缀大小写。`.ts` 优先作为 TypeScript 代码识别。
- 主文件名优先显示，最后一个有效后缀使用较小字号及次要文字色。文件夹、隐藏文件和无后缀文件保持完整名称；省略显示不改变完整标题及可访问名称。
- 卡片顶部放置复选框与操作菜单，避免覆盖预览。文字与日期保留 16–20px 边距。
- 多选支持批量移动和移入回收站；破坏性操作统一确认。目标重名时保留已有文件，按用户选择重命名或覆盖。

## 上传

文件工具栏的“新建文件夹”使用 secondary，“上传”使用 primary。“上传”打开**居中模态框**，提供“上传文件”和“上传文件夹”两项选择，手机端同样居中。选择文件夹保留目录结构。

空文件夹入口共用该模态框。工作区拖放使用覆盖浮层，不另设常驻上传卡片。传输面板显示进度、暂停、恢复、取消及失败状态。对话框支持键盘导航、Esc 关闭与焦点返回，打开时锁定背景滚动。

## 文件详情与预览

桌面详情框采用预览区与信息区两列，手机改为单列。信息区显示名称、类型、可读大小与精确字节数、上传时间，并提供下载按钮。文件名标题位于“名称”字段，不在模态框顶部重复显示。

| 类型 | 在线行为 |
| --- | --- |
| 图片 | 显示原图；读取或解码失败后显示统一提示 |
| 视频 | 仅显示服务器生成的静态封面，不播放视频 |
| 音频 | 使用浏览器音频控件；不支持的编码显示统一提示 |
| 文本、代码 | 仅展示受大小限制的 UTF-8 文本，内容按文本转义 |
| PDF、Office、安装包及其他格式 | 显示类型图标、“该类型不支持在线预览”及下载入口 |

文件未记录上传时间时显示“未记录”，不以修改时间冒充上传时间。关闭详情或切换文件时取消上一次文本请求，避免迟到响应覆盖当前文件。

## 访客分享页

单文件访客页只提供类型图标、基本信息和下载入口，**不渲染或请求文件图片、视频封面、PDF 或其他内容预览**。品牌 Logo 不属于文件内容。

页头安全标识使用锁图标与“安全加密分享”。文件名最多出现两处：卡片标题与下载区域，均分离主名和弱化的后缀。基本信息只列类型、大小和上传时间，不重复文件名。下载按钮为主视觉操作，使用完整宽度。长名称需要安全换行或省略，手机端不得横向溢出。

创建和修改分享共用八项有效期选择：5 分钟、1 小时、6 小时、12 小时、7 天、14 天、30 天、永久有效。时长从确认时开始计算，永久有效使用 null，不提供数字输入。撤销分享使用明确的风险说明、取消按钮和“撤销分享”确认按钮。

文件夹分享保留目录浏览与文件下载，不加入内容预览。失效、过期、撤销或文件缺失使用友好文案；连接异常与链接失效分开处理。

## 状态反馈与可访问性

- 我的分享与回收站的空面板最大宽度 640px，按内容撑开。企鹅尺寸 192px，配合极淡蓝色光晕，窄屏限制在容器宽度内。
- 成功、信息通知使用品牌蓝边线和图标，4.5 秒后关闭；警告、错误保留语义色并支持手动关闭。
- 原生模态框关联标题与描述，关闭时恢复焦点。菜单支持方向键、Home/End、Esc。
- 搜索提供清除按钮与 `/` 快捷键；输入或模态交互期间不抢占按键。
- 退出登录显示进度模态框，暂停上传并确认会话失效，失败时提供重试与返回。
- 装饰图标对读屏隐藏；图标按钮、复选框、设置表单和进度条具有明确的可访问名称与状态。
