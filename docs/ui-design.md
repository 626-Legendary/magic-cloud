# 前端设计实现

视觉规范参考本地 Design.md，修复依据见 [设计检查报告](design-review.md)。用户确认的默认网格、Hero.png、动态版权年份及 APP_VERSION 优先于早期文档。

## Token 与主题

`frontend/src/tokens.css` 定义色板、可访问颜色组合、4px 基础间距、6/10/12/16px 圆角、sm/md/lg 阴影、150/200/250ms 动效及弹层层级。`style.css` 使用这些 Token，品牌插画与固定布局尺寸单独定义。字号为 32/24/20/16/14/12px，品牌展示可使用 40px。

原始品牌蓝不适合直接用作所有文字和按钮状态。当前组合按相对亮度计算：

| 用途 | 前景 | 背景 | 对比度 |
| --- | --- | --- | --- |
| 浅色主按钮 | #FFFFFF | #0D6EFD | 约 4.50:1 |
| 浅色主按钮 Hover | #FFFFFF | #085CDB | 大于 4.5:1 |
| 深色主按钮 | #0B1220 | #267FFF | 约 4.96:1 |
| 深色主按钮 Hover | #0B1220 | #3B8FFF | 约 5.85:1 |
| 深色选中导航 | #A8D4FF | #234F86 | 约 5.34:1 |
| 深色链接 | #6BB8FF | #162238 | 约 7.52:1 |

文件类型采用可访问的主题衍生色，hover/选中后的元信息使用 text-secondary。按钮按压通过内描线反馈，避免整体调暗导致文字对比度降低。禁用控件保留明确不可操作状态。

## 交互约定

- 小于 768px 使用抽屉；关闭时 inert，打开时工作区 inert，焦点进入抽屉、Tab 循环、Esc 关闭并返回打开按钮。跨断点时关闭抽屉并清理滚动锁。
- 文件操作菜单支持方向键、Home/End、Esc 和原生按钮激活；关闭返回触发按钮。弹窗关联标题/描述，并在关闭后恢复焦点。
- 搜索保留可见焦点，提供清除按钮及 `/` 快捷键；输入文本或弹窗打开时不拦截 `/`。
- Grid 与 List 共用原生复选框及选择计数；列表表头可全选/取消选择。切换文件夹时清空选择，刷新内容时剔除已消失的对象。
- 列表行高 48px、表头 40px，大小与时间右对齐；窄屏只保留选择、名称与操作。网格始终显示修改时间并保持方形预览。
- 上传入口位于文件集合首位，网格时为上传卡片、列表时为首行；可点击或拖入，任务进行中显示总体进度。三个文件操作按钮始终保留标签和足够触控面积；排序方式使用带标签与可见边框的选择框。
- 多选提供批量移动和移入回收站。批量移动自动重命名同名项目并保留已有文件；批量回收站操作统一确认，服务器先校验整组选项并合并父子重复选择。
- 退出登录使用模态进度，先暂停上传，再请求退出并检查会话确实失效；请求有超时，失败提供重试和返回，不直接假定已退出。
- 通知位于右上 24px，支持 success/info/warning/danger。success/info 4.5 秒自动消失；warning/danger 需手动关闭。请求错误的持久 alert 继续保留。弹窗内产生的通知放入当前 dialog，避免被原生模态层遮挡。
- 操作图标采用 16/20/24px，线宽分别为 1.5/1.5/1.75；文件预览占位与错误插图可使用更大的展示尺寸。装饰图标对读屏隐藏，纯图标按钮有可访问名称，支持悬停的设备显示延迟 300ms Tooltip。

## 验证

`tests/design-browser.mjs` 为可重复的 Chromium 回归，需 Playwright 和 CDP 浏览器，且只可对全新、可丢弃的测试部署运行。必须提供 `MC_TEST_DISPOSABLE=1`、`MC_TEST_ORIGIN`（HTTP LAN 测试入口）和 `MC_TEST_PASSWORD`；可通过 `MC_BROWSER_CDP` 与 `MC_TEST_ARTIFACTS` 指定浏览器和输出目录。脚本会创建文件、上传任务和测试文件夹，不能对生产数据运行。

自动回归覆盖真实上传、类型识别、选择、列表尺寸、菜单与弹窗焦点、设置标签、主题对比度、移动抽屉和减少动效。截图及检查指标输出到指定目录；该回归不等同于完整屏幕阅读器或全站 WCAG 认证。

`tests/thumbnail-lifecycle.mjs` 使用 Node 验证上传后的主动生成、缓存复用、失败状态与删除清理。除上述可丢弃环境变量外，要求 `MC_TEST_STORAGE` 指向挂载的测试存储、`MC_TEST_VIDEO` 指向小于 16 MiB 的短 MP4 样本；脚本在请求缩略图接口之前检查后台输出。若测试环境提供 `.magic-cloud/ffmpeg-invocations` 计数日志，还会验证重复读取不增加解码次数。
